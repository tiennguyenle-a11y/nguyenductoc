🚀 Hướng Dẫn Deploy Website Tộc Nguyễn Đức

Đưa website lên Internet miễn phí bằng GitHub Pages – không cần thuê server

📋 Tổng quan

Phần 1 – Tạo tài khoản GitHub (nếu chưa có)

1

Truy cập github.com → Sign up

Điền email, mật khẩu và tên người dùng. Nên chọn tên ngắn gọn, ví dụ: tocnguyenduc hoặc nguyenduc-danang

💡 Tên tài khoản sẽ xuất hiện trong địa chỉ website: https://tên-tài-khoản.github.io/...
2

Xác nhận email và đăng nhập

GitHub sẽ gửi email xác nhận. Bấm link trong email rồi đăng nhập lại.

Phần 2 – Tạo kho lưu trữ (Repository)

1

Bấm nút + (góc trên phải) → New repository

2

Điền thông tin repository

  • Repository name: nguyen-duc-toc
  • Description: Website gia phả Tộc Nguyễn Đức, Phường Hòa Cường, TP. Đà Nẵng
  • Visibility: ✅ Public (bắt buộc để dùng GitHub Pages miễn phí)
  • Initialize with README: ☑️ Tick vào

→ Bấm Create repository

Phần 3 – Upload toàn bộ file website

📁 Toàn bộ file website nằm trong thư mục: output/website/ trên máy tính của bạn
1

Trong trang repository vừa tạo, bấm Add file → Upload files

2

Kéo thả toàn bộ nội dung thư mục output/website/ vào ô upload

Cần upload tất cả các file và thư mục con:

  • index.html, gia-pha.html, lich-su.html, tong-do.html, tin-tuc.html, lien-he.html
  • Thư mục css/, js/, data/, images/, events/
⚠️ Kéo thả nội dung bên trong thư mục website/, không kéo cả thư mục website
3

Bấm Commit changes ở phía dưới trang

Để nguyên commit message mặc định hoặc gõ: "Upload website Tộc Nguyễn Đức"

Phần 4 – Bật GitHub Pages

1

Vào tab Settings (thanh menu trong repository)

2

Thanh bên trái → mục Pages

3

Cấu hình Source

  • Source: chọn Deploy from a branch
  • Branch: chọn main · / (root)
  • Bấm Save
4

Chờ ~1–2 phút rồi F5 lại trang Settings → Pages

✅ Khi thấy dòng xanh: "Your site is live at https://[tên-tài-khoản].github.io/nguyen-duc-toc/" là xong!

Phần 5 – Cập nhật website sau này

🗞️ Thêm tin tức/sự kiện mới

1

Copy file events/_TEMPLATE_su-kien.html, đặt tên mới, điền nội dung

Ví dụ: 2026-ky-bac-toc.html

2

Mở events/events-index.json, thêm entry mới lên đầu mảng events

// Thêm vào đầu mảng "events": [ { "title": "Tên sự kiện", "date": "2026-05-20", "type": "ky", // ky | hop | le | thong | vui "summary": "Mô tả ngắn sự kiện", "file": "2026-ky-bac-toc.html" },
3

Upload 2 file mới lên GitHub → website tự cập nhật

Vào repository trên GitHub → Add file → Upload files → kéo 2 file vào → Commit

📋 Cập nhật thành viên mới trong gia phả

1

Mở file gen_genealogy.py, thêm thành viên mới

Gửi file cho mình (AI), mình sẽ thêm thành viên và tái tạo genealogy.json

2

Upload data/genealogy.json mới lên GitHub

Website gia phả sẽ tự cập nhật ngay sau khi commit.

Phần 6 – (Tùy chọn) Mua tên miền riêng

GitHub Pages (Miễn phí) Khuyến nghị

Địa chỉ: https://tocnguyenduc.github.io/nguyen-duc-toc/
Chi phí: 0 đồng/năm
Ổn định, không quảng cáo, không giới hạn lưu lượng

Tên miền riêng (Trả phí)

Địa chỉ: https://tocnguyenduc.vn
Chi phí: ~250.000–350.000 đ/năm
Hosting vẫn dùng GitHub Pages (miễn phí)
Mua tại: tenten.vn hoặc inet.vn

💡 Nếu mua tên miền riêng: vào Settings → Pages → Custom domain, điền tên miền vào và làm theo hướng dẫn của GitHub.

🙋 Cần hỗ trợ thêm?

Nếu gặp khó khăn trong quá trình deploy, chụp màn hình lỗi và gửi cho mình (AI) để được hỗ trợ. Mình cũng có thể hỗ trợ thêm sự kiện mới, cập nhật thành viên, hoặc chỉnh sửa giao diện bất cứ lúc nào.
